Titan Relics - Fabric mod for Minecraft Java 1.21.1 (10 items)

Build: push to GitHub; the included Actions workflow builds the jar
(download "relics-jar" from the run), or run `gradle build` locally with JDK 21.
Needs Fabric Loader 0.16+ and Fabric API for 1.21.1.

All items are in the "Titan Relics" creative tab. Or use /give @s relics:<id>
ids: thunder_scepter blink_staff meteor_staff lifebloom_staff blood_fang
     titan_pickaxe gale_fan black_hole_orb chrono_watch phoenix_feather
